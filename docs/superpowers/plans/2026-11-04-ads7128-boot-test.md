# ADS7128 Boot Test Implementation Plan

Historical plan: this standalone diagnostic was retired on 2026-11-09 in favor of selectable ADS7128 devices in the normal hardware builder. See `2026-11-09-ads7128-builder.md`.

**Goal:** Print all eight ADS7128 raw readings on the Liquid serial console at boot.

**Architecture:** Add an early diagnostic command to the existing Rust executable.
An optional Liquid image setting replaces the normal fill-station init entry with
that command and redirects output to the serial console.

**Tech Stack:** Rust, existing ADS7128 driver, Nix, BusyBox init.

- [x] Test explicit address validation, including rejection of other board devices.
- [x] Implement the diagnostic command with per-channel output and no actuator initialization.
- [x] Wire an opt-in boot setting and document serial use and bench checks.
- [x] Check address parsing and Nix init entries in isolation.
- [ ] Build the full image and validate on the physical board.
